# Brand masters — not deployed

Print and fabrication vectors. These are **not** referenced by the site and must not be
served from it. The web logos live in `assets/` as rasters, which carry the artwork's
gradient shading; these flat vectors deliberately do not.

| Variant | Use |
| --- | --- |
| `*-flat.svg` | Flat 3-colour — oxblood `#8E0B16`, gold `#BE9A42`, cream `#FCF7E9` |
| `*-2color.svg` | Oxblood + gold, cream dropped — foil, single-pass screen print |
| `*-mono.svg` | `fill="currentColor"`, veins knocked out with `fill-rule="evenodd"` — embroidery, deboss |

Traced from the committed `assets/logo-*.png` rasters, not drawn. Good enough for processes
that flatten to spot colour. If the original AI/EPS ever surfaces, replace these rather than
refine them.
